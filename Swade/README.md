# README

## Intro

Ci-dessous un petit contenu SWADE en français traduit par moi, et non compatible avec la traduction française officielle. Les compétences ont changé dans Swade en comparaison des éditions précédentes de SW.

## Création des PJs

### Attributs (attributes)

| Niveau       | Dé  |
|--------------|-----|
| Faible       | d4  |
| Moyen        | d6  |
| Fort         | d8  |
| Très fort    | d10 |
| Exceptionnel | d12 |

Attributs :

| Français     | Anglais  | Démarrage | Acronyme |
|--------------|----------|-----------|----------|
| Force        | Strength | d4        | FOR      |
| Dexterité    | Agility  | d4        | DEX      |
| Constitution | Vigor    | d4        | CON      |
| Intelligence | Smarts   | d4        | INT      |
| Pouvoir      | Spirit   | d4        | POU      |

Tous les attributs commencent à d4. Le joueur dispose de 5 points pour les augmenter : passer de d4 à d6 coûte 1 point.

Il est impossible d'augmenter un attribut à plus de d12 (sauf caractéristique de race). Dans ce cas, un point rapporte un pip (1 point => 1d12+1, 2 points => 1d12+2, etc.).

### Attributs dérivés

| Attr. dérivé | Anglais   | Formule              |
|--------------|-----------|----------------------|
| Vitesse      | Pace      | 12cm/round, 1cm=1m   |
| Parade       | Parry     | 2 + (Combat/2)       |
| Taille       | Size      | 0 (sauf exception)   |
| Résistance   | Toughness | 2 + (CON/2) + armure |

### Désavantages (hindrances) / Avantages (edges)

* Désavantages : Max 4 points/PJ
* Coût désavantage mineur : 1 point
* Coût désavantage majeur : 2 point

1 point :

* 1 point de compétence
* Fonds supplémentaires (2 fois le montant de départ)

### Compétences

Tous les PJs démarrent avec 5 compétences fondamentales à d4 :

| Attribut | Français                | Anglais          | Démarrage |
|----------|-------------------------|------------------|-----------|
| FOR      | Physique                | Athletics        | d4        |
| INT      | Connaissances générales | Common knowledge | d4        |
| POU      | Détection               | Notice           | d4        |
| POU      | Persuasion              | Persuasion       | d4        |
| DEX      | Discrétion              | Stealth          | d4        |

Le joueur dispose de 12 points pour ses compétences (1 point pour d4, 2 points pour d6, etc.). Si la compétence dépasse l'attribut, elle coûte 2 point pour atteindre le dé supérieur.

Il est impossible d'augmenter une compétence à plus de d12 (sauf exception). Dans ce cas, un point rapporte un pip (1 point => 1d12+1, 2 points => 1d12+2, etc.).
